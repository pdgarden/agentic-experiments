# Agentic experiments

- Each folder under `experiments/` is an independent project. Never share code, dependencies or config between experiments, and don't import across them.
- Work inside one experiment at a time; its own `CLAUDE.md` and `README.md` describe how to run and check it.
- When adding an experiment, give it its own README and `CLAUDE.md`, and add a row to the table in the root `README.md`.
